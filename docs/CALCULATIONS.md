# 計算方式

## 基礎代謝

日本Ganpule公式：

`BMR = (0.1238 + 0.0481×體重kg + 0.0234×身高cm − 0.0138×年齡 − 0.5473×性別碼)×1000/4.186`

男1、女2。此App估算範圍20～79歲一般成人；原日本樣本不代表所有亞洲族群。孕哺及特殊健康狀況不套公式。年齡須整數。

## 每日消耗與缺口

`基準 = BMR×基準倍率`（預設1.2，實務假設）

`活動總耗能 = kcal/kg/時參考率×體重×分鐘/60`

`額外活動淨增量 = MAX(0, 活動總耗能 − 基準×分鐘/1440)`

`每日總消耗 = 基準 + 額外活動淨增量合計`

`熱量缺口 = 每日總消耗 − 飲食攝取`

只有基準日以外增加的活動才算淨增。改變基準倍率後需重新界定額外活動。活動時段不可重疊；登錄總分鐘超過1440時不判讀。整日飲食與活動都確認完整、至少有1筆飲食且個人資料有效時才判讀缺口及納入累積。赤字正值、盈餘負值；不由缺口直接換算保證減掉的脂肪重量。

## 飲食

g／mL：`份量/100×每100單位營養值`；份：`份量×每1份營養值`。

額外油9kcal/g，額外糖4kcal/g。配料、油糖或料理調味已包含於成品值時不再添加。蛋白質未知留空，仍可計算熱量，但不判讀是否達蛋白質目標。生重、熟重与原品重不可任意互換。

## 心率

`參考最大心率 = 實測值，或208−0.7×年齡`

`HRR = (平均HR−靜息HR)/(最大HR−靜息HR)`

中等強度40%～<60%，費力60%～<90%，≥90%接近最大。未量測可以留空；平均心率低於靜息或高於最大參考時提示核對。心率不用於熱量推算，預估值不是安全上限。

## 建議與歷史

燃脂300kcal缺口、增肌200kcal盈餘及蛋白質1.6g/kg都是可調起始設定。BMI<18.5不設定燃脂攝取目標。低攝取提醒1500／1200kcal並非個人安全下限。用2～4週體重、腰圍及肌力趨勢校準。

每日紀錄保留個人資料及食物／活動快照。改項目只影響新紀錄，修改舊紀錄預設沿用原數值；改設定只套選取日及未來新日期。完整JSON保留所有資料，CSV只提供每日彙總。
